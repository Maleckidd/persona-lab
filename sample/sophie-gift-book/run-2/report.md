# Raport: Sophie, 34 — przebieg 2

## Jak poszło
I made the new cookbook "Mum's 60th - Family Recipes" easily, and I got Auntie Carol's trifle saved into it, but the ingredients came out with letters missing and the "3 hours" turned into a box symbol. I never found how to move Mum's shepherd's pie and Granny's Victoria sponge into the new book, and I didn't get as far as finding out whether I can make a PDF to print. It felt too fiddly on a crowded tram, so I gave up and will finish on the laptop. I don't trust it yet for a gift, so I'm not sure I'd keep using it for this.

## Problemy
- **[poważny]** The ingredients I typed in full came out cut short: "raspbe thawed", "jel", "ready-ma custar". I only saw this while typing and again when I opened the saved recipe. In a cookbook for my mum's birthday, typos I didn't make are a real problem. [shot-013](shots/shot-013.png) [shot-018](shots/shot-018.png)
- **[poważny]** "(about 3 hours)" in the method showed up as "(about ￼)", a strange box symbol, on the saved recipe page. The recipe would be wrong in a printed book. [shot-018](shots/shot-018.png)
- **[poważny]** I couldn't work out how to get my existing recipes (shepherd's pie, Victoria sponge) into the new cookbook. I didn't see any obvious "move" option, only Share, Edit and Delete in the recipe menu, so I stopped looking. [shot-019](shots/shot-019.png)
- **[poważny]** The Edit form still showed the cut-off words, so I'd have to retype the lines by hand with no guarantee they'd stay right. That was the point where I gave up. [shot-020](shots/shot-020.png)
- **[drobny]** The first tap on the title box didn't bring up the keyboard, and I had to tap twice. It also wasn't clear whether the box was focused, since the grey example text stayed visible. [shot-009](shots/shot-009.png) [shot-010](shots/shot-010.png) [shot-012](shots/shot-012.png)
- **[drobny]** After tapping "Add recipe", the screen seemed to lag, and I wasn't sure which screen I was on until I waited. [shot-007](shots/shot-007.png)

## Życzenia i inspiracje
- **I'd like a clear way to move or add existing recipes into a cookbook**, for example from the recipe menu or by selecting several at once. It would save me retyping when I'm collecting things for a gift. [shot-019](shots/shot-019.png)
- **I'd like the PDF option to be easy to find from inside the cookbook**, so I can see at once whether I can print it or send it to the print shop. I never found it in the time I had. [shot-017](shots/shot-017.png)
- **Save with a plain preview of how the recipe will look**, so I can spot mistakes before they go into a gift book. [shot-016](shots/shot-016.png)

## Uwagi końcowe
Creating the cookbook and the "Saved in..." message were nice and clear. But the missing letters and the box symbol made me stop trusting what I'd entered.
